# Risk Oversight Analytics

This repository contains a simplified Python workflow for supervisory-style reporting, data validation and dashboard generation.

The project is inspired by operational and analytical processes typically used in financial supervision and internal model oversight environments.

The workflow includes:
- data loading and preprocessing
- validation checks on supervisory datasets
- KPI generation
- reporting automation
- dashboard visualisation
- Excel export functionalities

The repository uses only dummy data and does not contain any confidential or proprietary information.

## Technologies
- Python
- pandas
- matplotlib
- openpyxl

## Structure

```text
data/     -> sample supervisory datasets
